# 조건문

1. `ansible_facts['distribution']`과 `ansible_facts['distribution_major_version']`을 조건으로, Ubuntu 24 계열에서만 실행되는 작업과 Debian 12 계열에서만 실행되는 작업을 각각 `when` 목록형으로 `conditions.yml`에 작성하세요.
2. `is match`와 `is search` 테스트를 이용해 호스트명 문자열이 `web-`로 시작하는지, 그리고 안에 노드 번호 패턴(숫자)이 포함돼 있는지 각각 확인하는 작업을 같은 파일에 추가하세요.
3. 임의의 버전 문자열 변수(`app_version: "3.10.2"`)를 만들어, `3.9` 이상인지 `is version(...)` 테스트로 확인하는 작업을 추가하세요.
4. `register`한 명령 결과에 대해 `is failed`, `is succeeded` 테스트를 사용하는 작업을 추가하세요 (`ignore_errors` 필요, 존재하지 않는 파일을 확인하는 명령을 쓰면 됩니다).
5. `conditions.yml`을 실행해 `skipping`으로 표시되는 작업과 `ok`로 표시되는 작업이 예상과 일치하는지 확인하세요.
